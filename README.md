# Perdido em Palmeira

## Configuração

1. Abra [`config.js`](config.js) e cole sua chave da **Maps JavaScript API** do
   Google Cloud Console em `window.GOOGLE_MAPS_API_KEY`.
2. Restrinja a chave por referenciador HTTP: `https://SEUUSUARIO.github.io/*`.
3. Salve — o GitHub Pages publica sozinho em 1-2 minutos.
